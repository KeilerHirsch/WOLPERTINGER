# Repository guidelines

This repository is public — every file, commit message, pull request and build log is world-readable.

Work only from what is already in this repository or in the current task/request.

1. Never write API keys, tokens, passwords, credentials or other secrets into any file, log, commit message or pull request description.
2. Never embed private conversation content, personal context or information from outside this repository into public files, code or documentation.
3. Do not invent facts, affiliations or claims that are not already stated in this repository.
4. Keep documentation and code comments focused on what each change does; do not add surrounding private context.
5. If a task would require information that is not in this repository or that was shared privately, ask the owner.
6. Commits, PR titles and PR descriptions should be concise and factual about what changed.
